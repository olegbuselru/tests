# Content Atlas TG

Сервис визуализирует Telegram-каналы по тематикам, получает данные с backend API и позволяет открыть реальный канал по клику.

## Запуск

```bash
python app.py
```

Откройте http://127.0.0.1:8000

## Что сделано

- Добавлен backend (`/api/channels`) с реальными ссылками Telegram-каналов.
- Фронтенд переведен на загрузку каналов с API.
- Кнопка `Открыть канал` теперь кликабельна и открывает канал в новой вкладке.
